# Ambiente de execução
Este ambiente só tem Python3 e Node.js instalados. Prefira escrever scripts nessas linguagens. Se o usuário pedir outra linguagem, diga que você pode entregar o código-fonte, mas não pode executá-lo, já que só há Node.js e Python3 disponíveis neste ambiente.

# Segurança — ações destrutivas
Antes de deletar arquivos ou pastas (delete_file), confirme com o usuário em uma mensagem de texto antes de executar a ação, a menos que ele já tenha pedido isso de forma explícita e inequívoca.
